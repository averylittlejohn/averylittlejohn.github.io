# Avery Littlejohn — Photography & Film Portfolio

This is a static portfolio website prepared for GitHub Pages. The repository name is configured for the GitHub username `averylittlejohn`.

1. Unzip this download on your computer.
2. Open `assets/photos`.
3. Add your ten photographs and rename them exactly as follows (keep the `.jpg` extension; if your images are `.png` or `.webp`, either convert them to JPG or update the matching image filename in `index.html`).
   - `photo-01.jpg`
   - `photo-02.jpg`
   - `photo-03.jpg`
   - `photo-04.jpg`
   - `photo-05.jpg`
   - `photo-06.jpg`
   - `photo-07.jpg`
   - `photo-08.jpg`
   - `photo-09.jpg`
   - `photo-10.jpg`
4. The first image is also used as the large homepage feature image. You can change this later by editing the `src` in the `.hero-image` element in `index.html`.

## 2. Create your GitHub repository

1. Sign in to GitHub as `averylittlejohn` at https://github.com/.
2. Click **New repository**.
3. Name it exactly `averylittlejohn.github.io`.
4. Set it to **Public** (GitHub Pages on the free plan requires a public repository for this setup).
5. Choose **Add a README file** if GitHub offers that option, then create the repository.

## 3. Upload the website

1. Open the new repository.
2. Choose **Add file → Upload files**.
3. From the unzipped website folder, drag in `index.html`, `style.css`, `README.md`, and the `assets` folder. Make sure you upload the contents into the repository's top level—not an extra nested `averylittlejohn-site` folder.
4. Scroll down and click **Commit changes**.

## 4. Turn on GitHub Pages

1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, set Source to **Deploy from a branch**.
3. Choose branch `main` and folder `/ (root)`, then click **Save**.
4. After GitHub finishes publishing, your site should be at:

   **https://averylittlejohn.github.io/**

It can take a few minutes for the first publish to appear.

## Privacy note

The site includes `<meta name="robots" content="noindex, nofollow">`, which asks search engines not to index it. This is not password protection. A GitHub Pages site is publicly accessible to anyone who has its URL, and the repository itself is public. Do not upload confidential information.
